# 极简英文 · 读与听 (Minimal English)

> 专为追求纯粹、沉浸式英语学习者打造的手机与电脑端极简「读文章 + 磨耳朵 + 生词本」闭环工具。

---

## ✨ 核心特色功能

### 1. 📖 沉浸式英文阅读（读文章）
- **无多余算法干扰**：纯粹存储、排版和沉浸式阅读属于你的英文文章。
- **点词即查、即存、即发音**：
  - 点击文章中任意单词，即刻弹出底栏：音标、中文简释、美音原生发音。
  - 支持调用 **DeepSeek AI** 进行**原句精准语境查词**，彻底解决一词多义搞不清的问题。
  - **文章实时联动高亮**：加入生词本后，该单词在文章中自动以极简暖色标注，再次阅读重点一目了然。
- **一键全文翻译对照**：支持一键展开/隐藏中英段落双语对照。

### 2. 🎧 极简精听与磨耳朵（听听力）
- **支持本地音频与文本智能朗读**：
  - 本地音频存入浏览器底层 **IndexedDB** 数据库，持久保存不消耗流量。
  - 支持纯文本 **TTS 智能朗读** 模式，无需音频亦可自动发音。
- **三大专属精听对照模式**：
  - **精听对照模式 (Read-Along)**：随播放进度自动高亮单句并平滑滚动跟随，轻点句子瞬间跳播。
  - **磨耳朵盲听模式 (Blind Mask)**：全篇原文采用毛玻璃遮蔽，逼迫耳朵听音理解；轻触句子即可刮开揭晓。
  - **听写核对模式 (Dictation & Diff)**：边听边键入英文句子，内置词级对比算法，绿色标出正确词汇，红色删除线标出漏听，橙色标出拼写误差，实时计算准确率得分！
- **专业播放控制**：
  - 单句循环复读、A-B 片段循环复读。
  - 句末跟读智能自动停顿（专为影子跟读 Shadowing 设计）。
  - 8 档精细变速（0.75x ~ 1.5x）、快捷快进快退。

### 3. 🧩 形近词智记（DeepSeek AI 赋能）
- **按考试范围精准匹配**：支持针对 **四级 (CET-4)、六级 (CET-6)、考研英语、雅思 (IELTS)、托福 (TOEFL)、高考** 等不同范围，提供一个或多个单词，自动联想高频易混形近词群。
- **字母微差与记忆锚点**：深度剖析形近词差异（如 `adapt` 中 a 联想 action 去适应，`adopt` 中 o 联想 option 做选择来采纳，`adept` 中 e 联想 expert 专家最熟练）。
- **趣味情景串记小故事**：通过一段构思巧妙的双语短篇故事将整组单词全景串联，并配以押韵速记口诀，彻底攻克扫读混淆痛点。
- **全站深度联动**：
  - 点击卡片支持一键将整组形近词收录到生词本；
  - 在阅读模式或听力中轻点单词，亦可一键调用「AI 形近词」极速拓展。

### 4. 📝 双向联动的全景生词本
- **读、听、形近词汇聚于一处**：无论是阅读文章、听力练习还是形近词智记中点击收录的生词，全部汇总在生词本中。
- **标记来源与上下文原句**：每张生词卡片标明来自哪篇文章、哪篇听力或哪组形近词，保留原句语境，点击来源标签瞬间跳回原文对应位置！
- **支持检索、掌握标记与文本一键导出**。

### 5. 🎨 极致美学与 100% 隐私安全
- **三套优雅护眼配色**：经典「暖阳纸」、清爽「极简白」与专注夜读「深邃夜」。
- **字体与字号随心调**：优雅衬线体 (Serif) 与清晰无衬线体 (Sans) 自由切换，字号滑块无级调节。
- **100% 本地隐私安全**：所有文章、音频、原文与生词完全保存在手机/电脑本地，支持一键导出完整 JSON 备份与迁移恢复。
- **PWA 原生体验**：支持添加到 iOS Safari 或 Android 桌面主屏幕，全屏无地址栏运行，离线亦可使用。

---

## 📱 手机添加到主屏幕方法
1. **iPhone (Safari)**：打开网址 ➔ 点击底部分享按钮 ➔ 选择「添加到主屏幕」。
2. **Android (Chrome / Edge)**：打开网址 ➔ 点击右上角菜单 ➔ 选择「添加到主屏幕」或「安装应用」。

---

## 💻 本地运行
在本地文件夹中双击 `start.bat`（或在终端运行 `python serve.py`），即可在本地浏览器体验。
